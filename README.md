# 华阳自营商城

一套可直接运行的自营电商平台，包含 **商城前台** 与 **商家后台**，覆盖从浏览、加购、下单、支付、发货到售后的完整交易链路。

## 启动

双击 `启动商城.bat`，或在当前目录执行：

```bash
node server.js
```

| 入口 | 地址 |
| --- | --- |
| 商城前台 | http://localhost:8080/ |
| 商家后台 | http://localhost:8080/admin |

| 角色 | 账号 | 密码 |
| --- | --- | --- |
| 管理员 | 13800000000 | admin123 |
| 测试会员 | 13900000001 | 123456 |

## 功能

**商城前台**

- 首页：轮播、六大分类、限时特惠、热销榜、新品
- 商品：分类/关键词/价格区间筛选、排序、分页、规格选择
- 购物车：勾选、改数量、删除、满 99 包邮提示
- 下单：收货地址、优惠券抵扣、订单备注、模拟支付
- 订单：状态分类、取消、支付、确认收货、物流与时间线
- 会员：积分、地址管理、我的优惠券、领券中心

**商家后台**（单层侧边菜单 + 页面内 Tab）

- 数据看板：今日销售额/订单、待发货、库存预警、近 7 日趋势、分类销售占比、TOP5、最新订单
- 商品管理：商品列表（新增/编辑/上下架/删除）、分类管理
- 订单管理：按状态筛选、订单详情、发货（快递公司 + 运单号）
- 库存管理：库存预警、修改总库存
- 营销中心：优惠券创建/删除、包邮门槛与运费配置
- 会员管理、店铺设置


## 说明

- 服务端为 **零第三方依赖**，仅需 Node.js 18+，无需 `npm install`。
- 数据存储在 `data/db.json`，删除该文件后重启即可恢复演示数据。
- 支付、短信、物流为模拟实现，便于本地演示完整流程；接入真实支付/物流需替换对应接口。
- 商品为 OTC 非处方药与健康类商品演示数据，实际经营需具备相应资质并按 GSP 规范管理。
